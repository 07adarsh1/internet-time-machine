Travel across computing history (1995 → 2026) with a real-time 3D Morphing Hardware Rig, authentic era-specific interactive mini-worlds, a Vintage Dev Inspector, an exportable Time Capsule Passport Generator, and a Dead Web Audio Vault.

## 🖥️ Overview

The Internet Time Machine avoids treating web history as a superficial CSS skin-swap. When you travel through time, both the physical computing hardware and the underlying website itself transform in lockstep:

- 1995 (The Dawn): Raw HTML 2.0, grey bevel tables, hit counters, and interactive guestbooks running on a beige CRT Trinitron monitor.
- 2000 (Dot-Com Boom): Marquees, animated GIFs, Flash 4.0 banners, and a dot-com bubble popping game running on a translucent Bondi-blue all-in-one.
- 2005 (The Social Web): MSN Messenger 7.5 simulator with working screen-shaking Nudges, MySpace Top 8 profile, and aqua glass buttons running on a flat LCD panel.
- 2010 (Skeuomorphism): Stitched leather, glossy aqua badges, early Facebook walls, and camera shutter flashes running on an aluminum/glass unibody slate.
- 2015 (Flat Design): Google Material Design cards, 6-second looping Vine video simulator, and pastel UI running on a slim laptop.
- 2020 (The Remote Era): Dark-mode Bento grids (#0d1117), Lo-Fi study beats audio visualizer, Discord lounges, and Zoom grids running on an OLED display.
- 2026 (The Spatial / Agentic Web): Ambient aurora glows, autonomous agent log streams, and intent-driven dynamic UI generation on a floating optic neural slab.

## ✨ Key Features

### 1. 🎛️ The 3D Morphing Hardware Rig (Landing Page)

- Continuous Geometry Morphing: Scrubbing the timeline smoothly reshapes the 3D hardware chassis from a 45cm CRT cathode tube cone down to a Bondi polycarbonate pod, an aluminum laptop, and a borderless OLED/optic glass slab.
- Dynamic Material State Machine: Real-time PBR material blending between injection-molded beige ABS plastic, translucent polycarbonate, brushed aluminum, and obsidian ceramic.
- Synchronized Screen Canvas: The display texture continuously renders live snapshots, CRT scanlines, and pixel matrices matching each historical era.
- Physical Media Props: Historically matched secondary props (3.5" Floppy Disk, AOL 500-Hours CD-ROM, iPod Classic, Micro-SIM card, MagSafe puck) slide onto the desk beside the rig.
- Boot Camera Dive: Clicking Turn On triggers a CRT degauss clack-buzz and dives the camera directly into the display plane to enter that era's world.

---

### 2. `</>` View Source Code Through Time (Vintage Dev Inspector)

A floating historical DevTools window that lets you inspect the actual markup and architecture patterns of every era:

- 1995: Uppercase `<TABLE BORDER="3">`, `<FONT COLOR="RED">`, `<MARQUEE>`, inline styles.
- 2000: Flash dual `<OBJECT>`/`<EMBED>` tags, `<FRAMESET>` splits, and raw JS popup scripts.
- 2005: Sliced table PNG sprites, `float: left` clearfix hacks, and raw jQuery `$(document).ready()` AJAX calls.
- 2010: `-webkit-gradient`, early responsive `@media (max-width: 768px)`, and CSS3 vendor prefixes.
- 2015: React 0.14 Class Components, Redux action reducers, and pure Flexbox.
- 2020: Full-stack Next.js, Tailwind CSS utilities, WebSockets, and TypeScript interfaces.
- 2026: Autonomous Agent Prompt Graph schema and neural vector streaming pipelines.
- Includes one-click code snippet copying and historical engineering context.

---

### 3. 📇 Time Capsule ID Generator (Exportable PNG Cards)

Visitors can create custom vintage digital passports and badges:

- 1995 Template: Netscape "Certified World Wide Web Explorer" Gold Seal Certificate.
- 2005 Template: MSN Messenger 7.5 "Buddy Profile Card" with custom status and top song.
- 2026 Template: Spatial Agent Citizen Passport with neural stream verification.
- Instant Canvas Export: Click Generate & Download PNG Card to export high-resolution shareable graphics for X, LinkedIn, or Discord.

---

### 4. 🔊 The Dead Web Audio Vault (Interactive Soundboard)

A vintage soundboard synthesizing iconic audio relics from early web history:

- 📻 AOL: "You've Got Mail!" fanfare.
- 📻 ICQ: The iconic "Uh-Oh!" horn.
- 📻 Windows 95: Brian Eno's ambient startup chime.
- 📻 Windows XP: The uplifting 4-chord Bliss fanfare.
- 📻 MSN Messenger: The explosive screen-shaking Nudge.
- 📻 Skype: Classic incoming marimba ringtone.
- 📻 56k Dial-Up: Modem carrier negotiation screech.
- 📻 iPod Classic: Mechanical piezo click-wheel rattle.

---

### 5. 🪦 The Internet Graveyard & 🎲 Surprise Roulette

- The Graveyard: Memorial tombstones for fallen digital icons (Adobe Flash, Vine, MSN Messenger, Orkut, Grooveshark, GeoCities, Google Reader) with interactive Light Candle / Press F to Pay Respects counters and Solfeggio 528Hz bell chimes.
- Surprise Me Roulette: Teleports visitors to obscure, pivotal milestones in digital history (for example, the NeXT CERN server, the $500B Y2K midnight, Tom Anderson's white T-shirt, and The Dress).

---

### 6. 🎚️ Retro Simulators & Controls

- CRT Mode: Vintage curvature overlay with scanlines, phosphors, and edge vignette.
- 56k Dial-Up Mode: Throttles transitions with simulated modem noise.
- Auto Evolve Player: Automatically advances the web through history every 4.5 seconds.
- Keyboard Navigation: Scrub seamlessly with `←` and `→` arrow keys; hit `Enter` to boot from the landing page.

## 🛠️ Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| Framework | React 19 | Component tree, hooks, and responsive lifecycle |
| Language | TypeScript 5.7 | Strict type definitions for eras, telemetry, and hardware schemas |
| 3D Engine | Three.js (WebGL) | Parametric geometry morphing, PBR shaders, dynamic canvas textures |
| Styling | Tailwind CSS 3.4 | Utility scaffolding + era-specific typographic design tokens |
| Icons | Lucide React | Clean UI icons for app chrome |
| Audio | Web Audio API | Pure procedural sound synthesis without external audio files |
| Build Tool | Vite 6 | Sub-millisecond HMR and optimized production bundling |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```bash
http://localhost:5173
```

---

## ⌨️ Keyboard Shortcuts

- Right Arrow: advance to the next internet era
- Left Arrow: travel back to the previous era
- Enter: boot or turn on the current era from the landing page
- F: pay respects in the Internet Graveyard

## 🚢 Production Build & Deployment

To generate an optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
